# 🏓 Пиклбол — игры и долги

Маленькое PWA-приложение для компании, которая играет в пиклбол разным составом:
кто забронировал и оплатил корт, кто играл, и **кто кому сколько должен**.

- Игры: дата, время, место, стоимость брони, кто платил, кто играл (любое число игроков). Создание, редактирование, удаление (с двойным подтверждением).
- Долги: стоимость игры делится поровну между игроками; показывается «кто → кому → сколько» в двух режимах:
  - **Минимум переводов** — взаимозачёт по всей компании;
  - **Напрямую** — каждый должен тому, кто платил за его игры.
  Кнопка «✓ Оплачено» записывает перевод, и долг исчезает. Есть таблица балансов и история переводов.
- Игроки: общий список, ник, добавление, переименование, архив (архивные не показываются при создании игры, история и долги сохраняются).
- Общие кошельки: несколько игроков (например, пара) играют каждый за себя, но в долгах считаются как один участник.
- Долги вручную: можно внести старые долги, которые были до начала учёта.
- Статистика: игры, часы и траты — всего и по каждому игроку, за всё время, год или месяц; график игр по месяцам.
- Мини-календарь прошедших и запланированных игр (нажатие на день фильтрует список).
- PWA: ставится на телефон, открывается без сети, изменения, сделанные офлайн, отправятся при появлении сети.
- Без сборки и зависимостей — обычные HTML/CSS/JS.

## Где хранятся данные

**Firebase Realtime Database** (бесплатный тариф Spark — его хватит с огромным запасом).
Приложение обращается к ней напрямую через REST API, без SDK и без ключей, и получает изменения в реальном времени
(открыл у себя — сразу видишь, что добавил друг). Доступ полностью публичный: читает и редактирует любой, у кого есть ссылка.

Пока адрес базы не указан, приложение работает в **локальном режиме** (данные только в этом браузере).

### Настройка базы (5 минут, один раз)

1. Откройте <https://console.firebase.google.com> → **Add project** (Google Analytics можно отключить).
2. В меню слева: **Build → Realtime Database → Create Database**. Регион любой (например, `europe-west1`), режим — **Start in test mode**.
3. Вкладка **Rules** → вставьте содержимое [`database.rules.json`](database.rules.json) и нажмите **Publish**:
   ```json
   { "rules": { ".read": true, ".write": true } }
   ```
   (в «test mode» доступ автоматически закроется через 30 дней — этот шаг делает его бессрочным).
4. Скопируйте адрес базы сверху страницы Data, вида `https://<project>-default-rtdb.europe-west1.firebasedatabase.app`.
5. Вставьте его в [`config.js`](config.js) → `databaseURL` и закоммитьте.

Проверить без коммита можно так: «Ещё» → «Общая база данных» → вставить адрес → «Применить на этом устройстве».

> ⚠️ Публичная база = любой со ссылкой может всё стереть. Для компании друзей это нормально, но
> иногда нажимайте «Ещё → Скачать JSON» — из этого файла всё можно восстановить.

## Публикация на GitHub Pages

1. Слейте ветку в `main`.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://harryburns.github.io/pickleball/`.

## Установка на телефон

- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

## Структура

| Файл | Что делает |
|---|---|
| `index.html`, `styles.css` | разметка и стили (светлая/тёмная тема) |
| `app.js` | интерфейс |
| `ledger.js` | расчёт долгов (в копейках, без ошибок округления) |
| `store.js` | хранилище: Firebase REST + SSE, офлайн-очередь, локальный режим |
| `config.js` | адрес базы данных |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |

Модель данных в базе:

```
players/{id}:  { name, handle, walletId, archived, createdAt }
wallets/{id}:  { name, createdAt }
games/{id}:    { date, time, duration, place, cost, payerId, players: {playerId: true}, note, createdAt, updatedAt }
payments/{id}: { kind: "payment" | "debt", fromId, toId, amount, date, note, createdAt }
settings:      { currency, seedVersion }
```

Каждая запись сохраняется отдельно, поэтому одновременные правки разных игр/игроков не затирают друг друга.

Локальный запуск: `python3 -m http.server 8080` в папке проекта → <http://localhost:8080>.
